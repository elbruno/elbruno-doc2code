# elbruno.Doc2Code — User Manual

elbruno.Doc2Code converts natural-language requirements documents into complete .NET solutions using a pipeline of six specialised AI agents. This manual walks you through the web interface.

## Getting Started

Launch the application and open the browser. The home screen displays the pipeline diagram, file upload area, and console panel.

![Getting Started](screenshots/01-home-idle.png)

1. Verify the pipeline nodes (Analyst → Architect → Developer → Reviewer → Testing → Documentation) are visible.
2. The console panel at the bottom shows connection status.

## Uploading a Document

Select a requirements file to begin code generation.

![Uploading a Document](screenshots/02-file-selected.png)

1. Click the upload area or drag-and-drop a `.txt` file onto it.
2. The filename appears once the file is accepted.
3. You may replace the file before starting generation.

## Starting Generation

Press the **Generate** button to launch the agent pipeline.

1. The first agent (Analyst) begins processing immediately.
2. Each subsequent agent activates when the previous one completes.

## Monitoring Pipeline Progress

Watch the pipeline diagram and console as agents work.

![Pipeline Visualization](screenshots/03-pipeline-diagram.png)

1. Active nodes are highlighted in the diagram.
2. Completed nodes show a check mark.
3. If the Reviewer scores below 70, the Developer re-generates (up to two retries).

## Viewing Console Logs

The console panel streams real-time messages from the backend.

![Console Output](screenshots/04-console-panel.png)

1. Log entries include timestamps and agent names.
2. Warnings and errors are highlighted.
3. Scroll up to review earlier messages.

## Downloading Results

After the pipeline completes, download the generated solution.

1. A download link appears once all agents finish.
2. The archive contains source files, tests, and documentation.

## Configuring Settings

Open the Settings page to adjust LLM provider, tools, and agent behaviour.

![Configuration](screenshots/05-settings-page.png)

1. Navigate to `/settings` using the sidebar or the "Settings" link on the Home page.
2. The Settings page uses a **tabbed layout** with four tabs:
   - **Agent Mode** — Select the LLM provider and configure provider-specific settings
   - **Agent Tools** — Toggle MCP and future tool integrations
   - **Agent Profiles** — Customize per-agent model, creativity, and instructions
   - **Source Control** — Configure GitHub token and owner/org for publishing

### LLM Providers

Select from four provider modes in the **Agent Mode** tab:

- **Local Ollama** — Use a locally running Ollama instance (default)
- **Local FoundryLocal** — Use a FoundryLocal model via its OpenAI-compatible endpoint
- **Azure AI Inference** — Use a cloud-hosted Azure AI model with endpoint + API key
- **GitHub Copilot** — Use GitHub Copilot SDK via the Copilot CLI (requires subscription)

Each provider shows a conditional settings panel with its required configuration fields.
Each panel includes a **[🔌 Test Connection]** button that verifies connectivity to the
provider and a **[❓ Help]** button that shows sample values and setup instructions.
Changes are persisted when you click **Save All Settings**.

### Agent Profiles

Expand an accordion to view or edit individual agent profiles.

![Agent Profiles](screenshots/06-agent-profiles.png)

1. Each profile shows the agent's model override, creativity slider, and custom instructions.
2. Adjust prompts or tune creativity per agent.

## Pipeline Designer

The Pipeline Designer lets you create custom agent pipelines with a visual drag-and-drop canvas. Add agents from the sidebar, connect them by dragging from output ports to input ports, and configure step-level properties in the inspector panel.

For full documentation, see [Pipeline Designer Guide](pipeline-designer.md).
